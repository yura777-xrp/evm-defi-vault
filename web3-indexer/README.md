# Web3 Ethereum Indexer

Rust-based Web3 indexer that connects to an Ethereum JSON-RPC endpoint and retrieves the latest block number.

## Stack
- Rust
- Tokio
- Reqwest
- Serde / JSON
- Ethereum JSON-RPC

## Features
- Async RPC requests
- Ethereum block number retrieval
- JSON serialization/deserialization
- Error handling
