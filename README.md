# EVM DeFi Vault

A minimal ERC-4626-style DeFi vault built with Solidity and Foundry.

## Features

- Mock ERC-20 token
- Deposit assets and receive vault shares
- Withdraw assets by burning shares
- Share-based accounting
- Deposit/withdraw tests
- Local deployment with Anvil

## Tech Stack

- Solidity 0.8.36
- Foundry
- Forge
- Anvil
